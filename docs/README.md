# Documentation

- [Features](features/) — one article per feature, grouped by category.
- [Roadmap](../ROADMAP.md) — what is done and what is not, as a checklist.
- [Handoff](../HANDOFF.md) — the state of things, and the traps already paid for.

Every article follows the same shape: **Behaviour**, **Configuration**,
**Failure modes**, **Security considerations**, **Verification**. The last
section names the test or capture that backs the article, so a claim here can
always be traced to something executable.
